# Neo Server Pack (packwiz)

Сборка для сервера `135.181.126.167:25737`, NeoForge 21.1.267 / MC 1.21.1, 184 мода.

Create и все его аддоны (включая физику Sable/Aeronautics) из сборки убраны.

Этот репозиторий — не только исходник пака, но и **хостинг**: GitHub Pages отдаёт
`pack.toml`, `index.toml`, `mods/*.pw.toml` и файлы, по которым обновляются инстансы игроков.

## Как обновить моды

```bash
packwiz modrinth add <slug>      # добавить мод с Modrinth
packwiz update --all             # обновить все моды до свежих версий
packwiz remove <name>            # убрать мод
packwiz refresh                  # пересчитать index.toml (обязательно после правок вручную)
git add -A && git commit -m "update mods" && git push
```

Моды, которых нет на Modrinth, лежат прямо в `mods/*.jar` — их достаточно заменить
файлом и выполнить `packwiz refresh`. Клиенты получат новый файл на следующем запуске.

## BerryUp — лаунчер для игроков

**Скачать:** <https://evilvalue.github.io/berry/launcher/BerryUp.exe>
(или из раздела Releases: <https://github.com/evilvalue/berry/releases/latest>)

`launcher/BerryUp.exe` — один файл: и установщик, и лаунчер (C# / .NET Framework 4.8,
уже есть в Windows 10/11). При первом запуске предлагает установку в
`%LOCALAPPDATA%\Programs\BerryUp`, делает ярлыки в меню «Пуск» и на рабочем столе и
добавляет запись в «Приложения и возможности»; удаление оттуда ничего не ломает:
экземпляр BerryTrip и сохранения остаются в Prism. Кнопка «Без установки» запускает
лаунчер прямо из папки загрузки.

`launcher/BerryUpSetup.exe` — тот же файл под старым именем, чтобы прежние ссылки работали.

Дальше лаунчер сам находит Prism Launcher или PineconeMC, ставит инстанс, синхронизирует пак
и запускает игру. Если лаунчер не найден — показывает окно со ссылками на скачивание.

### Автообновление лаунчера

При запуске BerryUp в фоне спрашивает `launcher/latest.json` и, если там версия новее,
показывает в окне плашку с выбором:

- **«Обновить»** — скачивает новую версию и сразу перезапускается в неё;
- **«При выходе»** — скачивает сейчас, а файл подменяет при закрытии: при следующем
  запуске уже новая версия, ничего не теряется;
- **«Позже»** — до следующего запуска.

Скачанное лежит в `%LOCALAPPDATA%\BerryUp\update`, сверяется по SHA-256 из `latest.json`.
Подмена — переименование работающего exe в `BerryUp.exe.old` и перенос нового файла на его
место; старый удаляется при следующем старте. Никаких `cmd.exe`, `.bat` и распаковки
в `%TEMP%` — те же правила, что и у установки.

Если интернет недоступен или `latest.json` нет — лаунчер просто работает дальше без
предупреждений.

### Как выпустить новую версию

1. Поднять `Version` в `app/BerryUp.cs` (и в `app/Info.cs`, `app/app.manifest`).
2. `powershell -ExecutionPolicy Bypass -File build\publish-launcher.ps1 -Notes "что нового"` —
   соберёт exe, положит его в `launcher/BerryUp.exe`, `launcher/BerryUpSetup.exe` и
   перепишет `latest.json` (версия, размер, sha256).
3. `git add -A; git commit; git push` — через минуту Pages отдаст новую версию,
   и все запущенные лаунчеры предложат обновиться.
4. По желанию: `gh release create v<версия> launcher/BerryUp.exe`.

### Про антивирусы

BerryUp не подписан сертификатом (он стоит денег и для сборки на друзей не нужен), поэтому
эвристики антивирусов иногда ругаются на скачанный exe. В коде специально нет того, что
вызывает такие срабатывания: нет вложенных exe в ресурсах, нет распаковки чего-либо в `%TEMP%`,
нет запуска `cmd.exe` и `.bat`, нет автозапуска и служб — программа работает только в папке
пользователя. У файла есть версия, издатель, описание и манифест (`asInvoker`, без прав
администратора), поэтому SmartScreen и антивирусы видят обычное подписанное-неподписанное
приложение, а не безымянный бинарник.

Если предупреждение всё же появилось: «Подробнее» → «Выполнить всё равно», либо добавить
файл в исключения. Отправить ложное срабатывание в Microsoft можно тут:
<https://www.microsoft.com/en-us/wdsi/filesubmission>.

В лаунчере есть кнопка **«Настройки памяти»**: можно по одной выключить 9 самых тяжёлых
клиентских модов, все ресурспаки и шейдеры, выбрать память под игру (4 / 6 / 8 ГБ) либо
нажать «Профиль 4 ГБ» — это освобождает примерно 300–500 МБ. Выбор хранится в
`%APPDATA%\BerryUp\tweaks.ini`; выключенные jar'ы переносятся в `minecraft\berry-off` и
возвращаются обратно перед синхронизацией packwiz, чтобы он не качал их заново.

## Что лежит внутри

- `config/**` — конфиги модов и графики (шейдеры отключены через `config/iris.properties`)
- `servers.dat` — сервер уже в списке multiplayer
- `mods/*.pw.toml` — 167 модов, качаются с CDN Modrinth (в паке только хеши)
- `mods/*.jar` — 17 модов CurseForge, отдаются прямо из этого репозитория
