# Файлы, которые сборка больше не поставляет.

# Лаунчер BerryTrip читает этот список после каждого обновления и удаляет
# перечисленные файлы у игроков. Это нужно для модов, убранных из пака: если
# старый jar остался в mods/, клиент объявляет каналы, которых нет на сервере,
# и NeoForge не пускает его на сервер.
#
# Формат строки: путь относительно папки игры, можно указать хеш через пробел.
#   mods/example.jar                — удалить файл
#   mods/example.jar sha512:<hex>   — удалить, только если файл байт-в-байт тот,
#                                     что раньше раздавала сборка
# Файлы, которые сборка по-прежнему содержит, никогда не удаляются, поэтому
# устаревшая строка здесь безопасна.
